# IoT-Based Smart Home Automation System using ESP32

## Overview

Developed an IoT-enabled home automation system for controlling household appliances using real-time scheduling and remote monitoring.

## Technologies Used

* ESP32
* RTC Module
* Blynk IoT Platform
* Arduino IDE

## Features

* Real-time appliance scheduling
* Remote monitoring and control
* Automated ON/OFF operations
* IoT-based smart automation

## Concepts Demonstrated

* Embedded Systems
* IoT Communication
* Hardware–Software Integration
* Real-Time Automation
