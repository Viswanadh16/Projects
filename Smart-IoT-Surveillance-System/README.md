# Smart IoT Surveillance System for Women Safety

## Overview

Designed and implemented a Raspberry Pi–based smart surveillance system with face recognition and IoT alert functionality.

## Technologies Used

* Raspberry Pi
* OpenCV
* Python
* IoT Alert System

## Features

* Face recognition
* Unauthorized person detection
* Real-time email alerts
* Smart surveillance monitoring

## Concepts Demonstrated

* Embedded Systems
* IoT Applications
* Computer Vision
* Security Automation
